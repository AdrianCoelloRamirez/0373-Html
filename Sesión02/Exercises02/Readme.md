📚 Mi Horario FP - Proyecto Web ASIX

Proyecto web estático desarrollado en HTML5 que muestra la planificación horaria semanal y la descripción de las asignaturas correspondientes al primer curso de ASIX (Administración de Sistemas Informáticos en Red).

📂 Estructura del Proyecto

/
├── index.html            # Página principal con el horario semanal (tabla de clases)
└── pages/
    └── asignaturas.html  # Página secundaria con el glosario de siglas y descripción de asignaturas


🛠️ Tecnologías Utilizadas

HTML5: Estructuración semántica mediante etiquetas (<header>, <main>, <section>, <article>, <footer>).

Tablas HTML: Uso de etiquetas avanzadas como <caption>, <thead>, <tbody>, <tfoot>, y atributos como scope, rowspan y colspan.

📄 Contenido de los Archivos

1. index.html (Horario Principal)

Encabezado (<header>): Presentación del proyecto y menú de navegación hacia el listado de asignaturas.

Sección Principal (<main>): Tabla completa con la distribución de clases de lunes a viernes, incluyendo las franjas horarias y el descanso.

Pie de página (<footer>): Información sobre el autor y el año del proyecto.

2. pages/asignaturas.html (Detalle de Asignaturas)

Glosario: Relación de siglas y abreviaturas comunes (como BBDD, IPO1, Sistemas S.).

Artículos (<article>): Descripción detallada de cada módulo cursado en el ciclo (Hardware, Inglés, Implantación web, Servicios, etc.).

🚀 Cómo Ejecutar el Proyecto

Clona o descarga los archivos en tu ordenador.

Abre la carpeta en tu editor de código (por ejemplo, Visual Studio Code).

Abre el archivo index.html en tu navegador web o utiliza una extensión de servidor local como Live Server.
