Resumen Html

  1. ¿Qué es Html?

    HTML (Lenguaje de Marcas de Hipertexto, del inglés HyperText Markup Language) es el componente más básico de la Web. Define el significado y la estructura del contenido web, utilizando "marcas" para etiquetar texto, imágenes y otro contenido para mostrarlo en un navegador Web. Las marcas HTML incluyen "elementos" especiales como <head>, <title>, <body>, <header>, <footer>, <article>, <section>, <p>, <div>, <span>, <img>, <aside>, <audio>, <canvas>, <datalist>,

  2. Otras tecnologias

    Además de HTML, generalmente se utilizan otras tecnologías para describir la apariencia/presentación de una página web (CSS) o la funcionalidad/comportamiento (JavaScript).

  3. Función del Hipertexto

    El hipertexto hace referencia a los enlaces que conectan páginas web entre sí, ya sea dentro de un único sitio web o entre sitios web. Los enlaces son un aspecto fundamental de la Web. Al subir contenido a Internet y vincularlo a las páginas creadas por otras personas, te conviertes en un participante activo en la «World Wide Web» (Red Informática Mundial).

  4. Etiquetas iniciales o de raíz

    En HTML todo funciona mediante etiquetas (van entre < y >). De las cuales las principales etiquetas son: <!DOCTYPE html> indica al navegador que el documento está basado en el estándar HTML5, y <html> que es donde se trabaja el resto de etiquetas.
